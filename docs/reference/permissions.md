# Permissions

| Handle | Description |
|---|---|
| `accessPlugin-net-terms` | View accounts, invoices, and payments. |
| `net-terms-manageAccounts` | Create, edit, and delete accounts, manage buyers, and add adjustments. |
| `net-terms-managePayments` | Create, issue, email, and void invoices, save and delete drafts, change their payment terms and notes, and record, apply, and reverse payments. |
| `net-terms-manageEmails` | Edit the invoice email and reminders in invoice billing. |
